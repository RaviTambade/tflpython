## ⚙️ Phase 2 — Modular Programming

#### *"Great Engineers Don't Repeat Themselves."*

Professional software isn't one giant program. It is divided into reusable building blocks.


###### 📚 Module 3 — Functions

Functions teach the computer reusable skills. Instead of writing

```python
print("Welcome Rahul")
print("Welcome Sneha")
print("Welcome Amit")
```

We write

```python
def welcome(name):
    print("Welcome", name)
```

Simple. Reusable. Professional.

#### Concepts

* Function Definition
* Parameters
* Return Values
* Scope
* Default Arguments
* Keyword Arguments
