## What are Control Structures?

Control structures determine **how a program flows**. Without them, every statement executes in order. With them, programs can:

* Make decisions
* Repeat tasks
* Solve problems intelligently

Think of control structures as the **traffic police** of your program. They decide which path to take and how many times to travel it.


## Decision Making using `if`

Suppose a website allows only adults to register. The logic is simple.

```text
If age is 18 or above
    Allow Registration
Else
    Reject Registration
```

Python code:

```python
age = int(input("Enter your age: "))

if age >= 18:
    print("You are eligible to vote.")
```

###### Sample Output

```text
Enter your age: 22
You are eligible to vote.
```

## `if...elif...else`

Real-world problems often have more than two choices.

Imagine grading students.

| Marks    | Grade       |
| -------- | ----------- |
| 75+      | Distinction |
| 60–74    | First Class |
| 40–59    | Pass        |
| Below 40 | Fail        |

Python Code

```python
marks = int(input("Enter Marks: "))

if marks >= 75:
    print("Distinction")
elif marks >= 60:
    print("First Class")
elif marks >= 40:
    print("Pass")
else:
    print("Fail")
```

## `for` Loop

A `for` loop is used when the number of repetitions is known.

Example

```python
for i in range(5):
    print("Welcome to Transflower")
```

Output

```text
Welcome to Transflower
Welcome to Transflower
Welcome to Transflower
Welcome to Transflower
Welcome to Transflower
```

## `while` Loop

A `while` loop repeats until a condition becomes false. Think of a lift. It keeps moving while there are requested floors. Python Example

```python
count = 1

while count <= 5:
    print(count)
    count += 1
```

Output

```text
1
2
3
4
5
```


## Difference Between `for` and `while`

| `for` Loop                                | `while` Loop                          |
| ----------------------------------------- | ------------------------------------- |
| Number of iterations is usually known     | Repeats until a condition changes     |
| Best for lists, ranges, sequences         | Best for menus, games, repeated input |
| Automatically advances through a sequence | You update the condition manually     |


## Nested Control Structures

Programs often combine decisions and loops.

Example

```python
for i in range(1,6):
    if i % 2 == 0:
        print(i,"is Even")
    else:
        print(i,"is Odd")
```

Output

```text

2 is Even
3 is Odd
4 is Even
5 is Odd
```

## Project – Number Guessing Game

#### Problem Statement

Build a game in which the computer randomly chooses a number between **1 and 100**. The user keeps guessing until the correct number is found. After every incorrect guess, the program provides a hint indicating whether the guess is **too high** or **too low**.


#### Algorithm

1. Import the `random` module.
2. Generate a random number between 1 and 100.
3. Ask the user to guess the number.
4. If the guess is too low, display **"Too Low"**.
5. If the guess is too high, display **"Too High"**.
6. Repeat until the user guesses correctly.
7. Display the number of attempts taken.


#### Python Program

```python
import random

secret_number = random.randint(1, 100)
attempts = 0

print("=== Number Guessing Game ===")
print("I have selected a number between 1 and 100.")

while True:
    guess = int(input("Enter your guess: "))
    attempts += 1

    if guess < secret_number:
        print("Too Low! Try Again.")
    elif guess > secret_number:
        print("Too High! Try Again.")
    else:
        print("🎉 Congratulations!")
        print("You guessed the correct number.")
        print("Attempts:", attempts)
        break
```

#### Sample Output

```text
=== Number Guessing Game ===
I have selected a number between 1 and 100.

Enter your guess: 40
Too Low! Try Again.

Enter your guess: 75
Too High! Try Again.

Enter your guess: 63
Too Low! Try Again.

Enter your guess: 68
🎉 Congratulations!
You guessed the correct number.
Attempts: 4
```
