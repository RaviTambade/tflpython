# Transaction Management Using Bank Accounts

Let's build a simple Bank Account Transaction Management System using Python and MySQL Connector.

The objective is to understand how database transactions work through a practical banking example.

We will implement:

1. Create bank accounts.
2. Deposit money.
3. Withdraw money.
4. Transfer money between accounts.
5. Maintain transaction history.
6. Use `COMMIT` and `ROLLBACK` to maintain data consistency.

## 1. Understand the banking transaction

Consider two bank accounts:

| Account | Account holder | Balance |
| ------- | -------------- | ------- |
| 101     | Amit           | ₹10,000 |
| 102     | Sneha          | ₹5,000  |

Amit wants to transfer ₹2,000 to Sneha.

The transaction involves two database operations:

- Debit ₹2,000 from Amit.
- Credit ₹2,000 to Sneha.

Both operations must succeed together.

Bank transfer – ₹2,000

Amit – 101

# ₹8,000

− ₹2,000 Debit

Sneha – 102

# ₹7,000

\+ ₹2,000 Credit

Total balance remains ₹15,000

Important: If the debit succeeds but the credit fails, the debit must be rolled back. This is why we need database transactions.

## 2. Understand ACID properties

Database transactions follow four important properties.

| Property    | Meaning                                             | Banking example                |
| ----------- | --------------------------------------------------- | ------------------------------ |
| Atomicity   | All or nothing                                      | Debit and credit together      |
| Consistency | Valid database state                                | No negative balance            |
| Isolation   | Concurrent transactions don't interfere incorrectly | Two transfers at the same time |
| Durability  | Committed data persists                             | Transfer remains recorded      |

## 3. Create MySQL database

We will create two tables:

- `accounts` – stores account information and current balance.
- `transactions` – maintains transaction history.

Execute in MySQL Workbench:

```
CREATE DATABASE banking_db;

USE banking_db;

CREATE TABLE accounts
(
    account_id INT PRIMARY KEY,
    holder_name VARCHAR(100) NOT NULL,
    balance DECIMAL(12,2) NOT NULL DEFAULT 0,
    CHECK (balance >= 0)
) ENGINE=InnoDB;

CREATE TABLE transactions
(
    transaction_id INT PRIMARY KEY AUTO_INCREMENT,
    from_account INT NULL,
    to_account INT NULL,
    amount DECIMAL(12,2) NOT NULL,
    transaction_type VARCHAR(20) NOT NULL,
    transaction_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    status VARCHAR(20) NOT NULL,

    FOREIGN KEY (from_account)
        REFERENCES accounts(account_id),

    FOREIGN KEY (to_account)
        REFERENCES accounts(account_id),

    CHECK (amount > 0)
) ENGINE=InnoDB;
```

## 6. Implement money transfer – transaction.py

This is the most important part of our lab.

```
from decimal import Decimal
from mysql.connector import Error
from database import get_connection


def transfer_money(from_account, to_account, amount):

    if from_account == to_account:
        print("Source and destination must differ")
        return

    amount = Decimal(str(amount))

    if amount <= 0:
        print("Amount must be positive")
        return

    connection = get_connection()
    cursor = connection.cursor(dictionary=True)

    try:

        # Start transaction
        connection.start_transaction()

        # Lock both account rows in consistent order
        account_ids = sorted([from_account, to_account])

        cursor.execute(
            """
            SELECT account_id, balance
            FROM accounts
            WHERE account_id IN (%s, %s)
            ORDER BY account_id
            FOR UPDATE
            """,
            tuple(account_ids)
        )

        accounts = {
            row["account_id"]: row["balance"]
            for row in cursor.fetchall()
        }

        if len(accounts) != 2:
            raise Exception("Account not found")

        # Check available balance
        if accounts[from_account] < amount:
            raise Exception("Insufficient balance")

        # Debit source account
        cursor.execute(
            """
            UPDATE accounts
            SET balance = balance - %s
            WHERE account_id = %s
            """,
            (amount, from_account)
        )

        # Credit destination account
        cursor.execute(
            """
            UPDATE accounts
            SET balance = balance + %s
            WHERE account_id = %s
            """,
            (amount, to_account)
        )

        # Record transaction
        cursor.execute(
            """
            INSERT INTO transactions
            (from_account, to_account, amount,
             transaction_type, status)
            VALUES (%s, %s, %s, %s, %s)
            """,
            (
                from_account,
                to_account,
                amount,
                "TRANSFER",
                "SUCCESS"
            )
        )

        # Save all changes together
        connection.commit()

        print("Transfer completed successfully!")

    except Exception as error:

        # Undo all uncommitted changes
        connection.rollback()

        print("Transaction failed:", error)
        print("All changes rolled back.")

    finally:

        cursor.close()
        connection.close()
```

## 9. Extend the application – Deposit and Withdrawal

Add two more functions to `transaction.py`.

Deposit money

```

def deposit(account_id, amount):

    amount = Decimal(str(amount))

    if amount <= 0:
        print("Invalid deposit amount")
        return

    connection = get_connection()
    cursor = connection.cursor()

    try:
        connection.start_transaction()

        cursor.execute(
            """
            SELECT account_id
            FROM accounts
            WHERE account_id = %s
            FOR UPDATE
            """,
            (account_id,)
        )

        if cursor.fetchone() is None:
            raise Exception("Account not found")

        cursor.execute(
            """
            UPDATE accounts
            SET balance = balance + %s
            WHERE account_id = %s
            """,
            (amount, account_id)
        )

        cursor.execute(
            """
            INSERT INTO transactions
            (to_account, amount, transaction_type, status)
            VALUES (%s, %s, 'DEPOSIT', 'SUCCESS')
            """,
            (account_id, amount)
        )

        connection.commit()
        print("Deposit successful!")

    except Exception as error:
        connection.rollback()
        print("Deposit failed:", error)

    finally:
        cursor.close()
        connection.close()

```

Withdrawal money

```
def withdraw(account_id, amount):

    amount = Decimal(str(amount))

    if amount <= 0:
        print("Invalid withdrawal amount")
        return

    connection = get_connection()
    cursor = connection.cursor()

    try:
        connection.start_transaction()

        cursor.execute(
            """
            SELECT balance
            FROM accounts
            WHERE account_id = %s
            FOR UPDATE
            """,
            (account_id,)
        )

        result = cursor.fetchone()

        if result is None:
            raise Exception("Account not found")

        if result[0] < amount:
            raise Exception("Insufficient balance")

        cursor.execute(
            """
            UPDATE accounts
            SET balance = balance - %s
            WHERE account_id = %s
            """,
            (amount, account_id)
        )

        cursor.execute(
            """
            INSERT INTO transactions
            (from_account, amount, transaction_type, status)
            VALUES (%s, %s, 'WITHDRAWAL', 'SUCCESS')
            """,
            (account_id, amount)
        )

        connection.commit()
        print("Withdrawal successful!")

    except Exception as error:
        connection.rollback()
        print("Withdrawal failed:", error)

    finally:
        cursor.close()
        connection.close()
```

## 11. Student practical exercises

Hands-on Lab

Ask students to implement these scenarios:

| Scenario                     | Expected result           |
| ---------------------------- | ------------------------- |
| Deposit ₹5,000               | Balance increases         |
| Withdraw ₹1,000              | Balance decreases         |
| Transfer ₹2,000              | Both accounts updated     |
| Withdraw more than balance   | Transaction rejected      |
| Transfer to invalid account  | Rollback                  |
| Transfer ₹0                  | Validation error          |
| Transfer to same account     | Validation error          |
| Execute concurrent transfers | Maintain correct balances |

Important production considerations: Use database credentials from environment variables, keep the transaction history immutable, handle deadlocks with bounded retries, and never expose sensitive account information. For a real banking system, also introduce transaction reference IDs, idempotency, authorization and audit logging.

## 12. What students should understand

The most important learning is the difference between these three database operations:

| Operation    | Responsibility                       |
| ------------ | ------------------------------------ |
| `execute()`  | Execute SQL command                  |
| `commit()`   | Permanently save transaction changes |
| `rollback()` | Undo uncommitted transaction changes |

Mentor's takeaway:

A database is not just a place to store records. It is a system that maintains business integrity. This is where students begin understanding the relationship between Python programming, SQL, database concurrency, and enterprise application development.
