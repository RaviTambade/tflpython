**Theme:** Combine reusable authentication, test data, page objects, and parallel execution without sacrificing isolation.

## 2. Represent test data

```python
from dataclasses import dataclass
from typing import Literal


@dataclass(frozen=True)
class Assessment:
    title: str
    duration_minutes: int
    difficulty: Literal["easy", "medium", "hard"]


def new_assessment() -> Assessment:
    from uuid import uuid4

    return Assessment(
        title=f"Automation assessment {uuid4().hex[:10]}",
        duration_minutes=30,
        difficulty="medium",
    )
```

Use a schema-validation library when untrusted API data needs runtime validation. Dataclasses and annotations alone do not validate a JSON response.

## 3. Authenticate for API tests

```python
import os
from collections.abc import Iterator

import pytest
from playwright.sync_api import APIRequestContext, Playwright


@pytest.fixture
def api_base_url() -> str:
    value = os.environ.get("API_BASE_URL")
    if not value:
        pytest.fail("Set API_BASE_URL to the test API URL")
    return value.rstrip("/")


@pytest.fixture
def student_api(
    playwright: Playwright, api_base_url: str
) -> Iterator[APIRequestContext]:
    username = os.environ.get("STUDENT_USERNAME")
    password = os.environ.get("STUDENT_PASSWORD")
    if not username or not password:
        pytest.fail("Student test credentials are not configured")

    context = playwright.request.new_context(base_url=api_base_url)
    try:
        response = context.post(
            "/api/auth/login",
            data={"username": username, "password": password},
        )
        assert response.status == 200, "Student test account could not authenticate"
        token = response.json().get("accessToken")
        assert token, "Login response did not contain accessToken"
    finally:
        context.dispose()

    authenticated = playwright.request.new_context(
        base_url=api_base_url,
        extra_http_headers={"Authorization": f"Bearer {token}"},
    )
    yield authenticated
    authenticated.dispose()
```

Do not log or persist the token. Adapt the token field and login response to the real API. Cookie-based applications should use the documented cookie flow rather than assuming a bearer token.

## 4. Reuse browser authentication carefully

Browser authentication state can be saved using `browser_context.storage_state(path=...)` and loaded into a new context. This
can save time, but the state file contains credentials or session material: store it outside source control, restrict access, and regenerate it when it expires. Do not share one mutable browser context across parallel tests.

Prefer a setup flow that authenticates a dedicated test account and verifies the resulting state before dependent tests run. If roles have different permissions, keep distinct state per role.

## 5. Page objects and fixtures

Use a page object for repeated page actions and locators, not as a place to hide assertions for every scenario. Inject Playwright's page fixture into the object, and keep each test's expected outcomes explicit.

```python
from playwright.sync_api import Page


class AssessmentPage:
    def __init__(self, page: Page) -> None:
        self.page = page

    def open(self, base_url: str) -> None:
        self.page.goto(f"{base_url}/assessments")

    def open_assessment(self, title: str) -> None:
        self.page.get_by_role("link", name=title).click()
```

## 6. Parallel runs and unique data

Install `pytest-xdist` when parallel execution is needed:

```bash
python -m pip install pytest-xdist
pytest -n 2
pytest -n auto
```

Parallel tests must not depend on execution order or share records that they modify. Use unique identifiers, per-test browser contexts, separate accounts where necessary, and cleanup scoped to each test's own data. Begin with a small worker count and investigate flaky failures before increasing it.

Use pytest's failure output, Playwright traces, screenshots, and HTML reports to diagnose failures. Protect artifacts that may contain personal data, passwords, tokens, or private application content.
