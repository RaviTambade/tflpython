# Lesson 3: Build your first Playwright + Python browser suite

**Theme:** Automate a complete login journey using pytest and a real browser.

## 1. What we are testing

For a sample server-rendered login application, verify the login page, valid and invalid credentials, required fields, successful dashboard navigation, and access-control behavior. Routes, labels, and expected messages must match the application under test.

```text
pytest -> pytest-playwright -> browser -> web application -> services
```

## 2. Install and create the project

```bash
python -m pip install pytest pytest-playwright
python -m playwright install chromium
```

Suggested structure:

```text
playwright-python/
    pages/
        login_page.py
    tests/
        conftest.py
        test_login.py
    pytest.ini
    .gitignore
```

Set the application's base URL through the environment rather than embedding machine-specific addresses in every test.

`pytest.ini`:

```ini
[pytest]
testpaths = tests
addopts = -ra
```

`tests/conftest.py`:

```python
import os

import pytest


@pytest.fixture(scope="session")
def base_url() -> str:
    value = os.environ.get("BASE_URL")
    if not value:
        pytest.fail("Set BASE_URL to the test application's URL")
    return value.rstrip("/")
```

The `page` fixture is supplied by `pytest-playwright`. It creates an isolated
browser page and manages cleanup.

## 3. First test and reliable locators

```python
from playwright.sync_api import Page, expect


def test_login_page_is_available(page: Page, base_url: str) -> None:
    page.goto(f"{base_url}/Account/Login")
    expect(page).to_have_title("Sign in")
    expect(page.get_by_label("Username")).to_be_visible()
    expect(page.get_by_label("Password")).to_be_visible()
    expect(page.get_by_role("button", name="Sign in")).to_be_enabled()
```

Locator preference:

1. `get_by_role()` with an accessible name.
2. `get_by_label()` for form controls.
3. `get_by_placeholder()` when it is meaningful and stable.
4. `get_by_test_id()` for a deliberate test contract.
5. CSS/XPath only when the UI provides no better stable hook.

Locators are evaluated when used and Playwright retries many assertions until the configured timeout. This is more reliable than selecting an element once and adding arbitrary sleeps.

## 4. Encapsulate page operations

`pages/login_page.py`:

```python
from playwright.sync_api import Page


class LoginPage:
    def __init__(self, page: Page) -> None:
        self.page = page

    def open(self, base_url: str) -> None:
        self.page.goto(f"{base_url}/Account/Login")

    def submit(self, username: str, password: str) -> None:
        self.page.get_by_label("Username").fill(username)
        self.page.get_by_label("Password").fill(password)
        self.page.get_by_role("button", name="Sign in").click()
```

## 5. Test successful and rejected login

Credentials should come from a dedicated test secret store or environment variables, never from committed source code.

```python
import os

import pytest
from playwright.sync_api import Page, expect

from pages.login_page import LoginPage


def test_valid_user_reaches_dashboard(page: Page, base_url: str) -> None:
    username = os.environ.get("TEST_USERNAME")
    password = os.environ.get("TEST_PASSWORD")
    if not username or not password:
        pytest.fail("Set TEST_USERNAME and TEST_PASSWORD for the test account")

    login = LoginPage(page)
    login.open(base_url)
    login.submit(username, password)

    expect(page).to_have_url(f"{base_url}/Dashboard")
    expect(page.get_by_role("heading", name="Dashboard")).to_be_visible()


def test_invalid_password_shows_error(page: Page, base_url: str) -> None:
    login = LoginPage(page)
    login.open(base_url)
    login.submit("invalid-user@example.test", "invalid-password")

    expect(page.get_by_role("alert")).to_contain_text("Invalid credentials")
```

Use non-production accounts and data. A real login test must not print or attach passwords or session tokens to test output.

## 6. Run, debug, and report

```bash
pytest
pytest --browser chromium
pytest --headed
pytest --slowmo 250
pytest --tracing retain-on-failure
```

Use `pytest -k login` to select tests by name. Add an HTML report with `python -m pip install pytest-html`, then run `pytest --html=report.html --self-contained-html`. Keep generated reports and traces out of source control if they contain sensitive application data.
