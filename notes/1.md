# Project 1 – Simple Calculator

## Problem Statement

Design a calculator that performs addition, subtraction, multiplication, and division on two numbers entered by the user.

### Algorithm

1. Read two numbers from the user.
2. Read the operation (`+`, `-`, `*`, `/`).
3. Perform the selected operation.
4. Display the result.

### Python Program

```python
num1 = float(input("Enter first number: "))
num2 = float(input("Enter second number: "))

operation = input("Enter operation (+, -, *, /): ")

if operation == "+":
    result = num1 + num2
elif operation == "-":
    result = num1 - num2
elif operation == "*":
    result = num1 * num2
elif operation == "/":
    if num2 != 0:
        result = num1 / num2
    else:
        result = "Division by zero is not allowed."
else:
    result = "Invalid operation."

print("Result:", result)
```

### Sample Output

```
Enter first number: 10
Enter second number: 5
Enter operation (+, -, *, /): *
Result: 50.0
```

# Project 2 – To-Do List Manager

## Problem Statement

Create a simple program that allows users to add tasks and display the complete list of tasks.

### Algorithm

1. Create an empty list.
2. Ask the user how many tasks they want to add.
3. Read each task and store it in the list.
4. Display all tasks with their task numbers.

### Python Program

```python
tasks = []

count = int(input("How many tasks do you want to add? "))

for i in range(count):
    task = input("Enter task: ")
    tasks.append(task)

print("\nYour To-Do List:")

for index, task in enumerate(tasks, start=1):
    print(f"{index}. {task}")
```

### Sample Output

```
How many tasks do you want to add? 3

Enter task: Learn Python
Enter task: Practice Coding
Enter task: Complete Assignment

Your To-Do List:
1. Learn Python
2. Practice Coding
3. Complete Assignment
```
