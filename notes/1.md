# 6️⃣ Variables — Let's Store Insurance Data

Now the application needs data. A customer may have:


Let's represent that in Python:

Python determines the type from the value.

# 1️⃣1️⃣ Indentation — Python's Braces

Now comes an important Python characteristic. In C#, Java or C++ we write:

```text
if (...)
{
    ...
}
```

Python uses indentation:

```python
if premium > 20000:
    print("High premium policy")
```

The indentation tells Python:  “This statement belongs to the `if` block.” For example:

```python
if premium > 20000:
    print("High premium policy")

print("Policy processing completed")
```

The second statement is outside the `if`. So remember:  **In Python, whitespace is part of the program structure.**

# 1️⃣4️⃣ Create a Customer Class

Let's model a real insurance customer:

```python
class Customer:

    def __init__(self, name, age):
        self.name = name
        self.age = age

    def display(self):
        print("Customer:", self.name)
        print("Age:", self.age)
```

Create an object:

```python
customer1 = Customer("Sneha", 28)
```

Then:

```python
customer1.display()
```

Output:

```text
Customer: Sneha
Age: 28
```

Now we are no longer just writing Python syntax. We are **modeling the insurance domain**.

---

# 1️⃣5️⃣ Create a Policy

```python
class Policy:
```

# 🌸 Mentor's Important Correction

Friends, one point from our earlier discussion needs to be corrected. We often say:  **“Python is interpreted and runs line by line.”**
That's a useful beginner-level mental model, but technically CPython normally **compiles Python source into bytecode** and executes that bytecode on the Python virtual machine.

Conceptually:

```text
hello.py
   ↓
Python interpreter
   ↓
Bytecode
   ↓
Python Virtual Machine
   ↓
Execution
```

You normally don't see a Windows `.exe` generated simply by running:

```bash
python hello.py
```

But that doesn't mean Python has **no compilation stage at all**. Similarly, Python can generate cached bytecode such as:

```text
__pycache__/
```

So remember: **“Interpreted language” is a useful high-level description, but don't confuse it with “no compilation happens anywhere.”**
 
# 🌸 Another Important Mentor Correction

We also need to separate two ideas:

### Python is open source

The **Python implementation**—such as CPython—is open source. Your `.py` file is source code. Your Python program is readable source code because **you wrote it as source code**. These are related ideas, but they are not the same thing. A `.py` file being readable does **not by itself prove that the software is open source**. Open source also involves the **license and permissions** that allow others to inspect, modify and redistribute the software. That's an important lesson for future software engineers.
