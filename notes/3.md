# What is a Function?

A **function** is a named block of code that performs a specific task. Think of it like a **machine**.

```text
             Input
               │
               ▼
      +----------------+
      |    Function    |
      +----------------+
               │
               ▼
            Output
```

Examples from daily life:

| Machine         | Input                 | Output        |
| --------------- | --------------------- | ------------- |
| Coffee Machine  | Coffee Powder + Water | Coffee        |
| ATM             | Card + PIN            | Cash          |
| Washing Machine | Dirty Clothes         | Clean Clothes |
| Python Function | Arguments             | Result        |

# Scope of Variables

Imagine a classroom. A student's notebook belongs only to that student. Other students cannot directly use it. Similarly, variables created inside a function belong only to that function. These are called **Local Variables**.

```python
def demo():
    message = "Hello"

    print(message)

demo()
```

Works perfectly.

But

```python
print(message)
```

Produces an error because `message` exists only inside the function.



# Global Variables

Variables declared outside all functions are called **Global Variables**.

```python
college = "Transflower"

def display():
    print(college)

display()
```

Output

```text
Transflower
```

# Local vs Global Variables

| Local Variable                        | Global Variable                        |
| ------------------------------------- | -------------------------------------- |
| Created inside a function             | Created outside functions              |
| Accessible only within that function  | Accessible throughout the program      |
| Exists only during function execution | Exists for the lifetime of the program |


# Function Arguments

Python supports several ways of passing arguments.

### Positional Arguments

```python
def multiply(a, b):
    print(a * b)

multiply(5, 4)
```


### Keyword Arguments

```python
def employee(name, department):
    print(name, department)

employee(department="HR", name="Ravi")
```

### Default Arguments

```python
def greet(name="Student"):
    print("Welcome", name)

greet()

greet("Anita")
```

Output

```text
Welcome Student
Welcome Anita
```

# Project – Text-Based Adventure Game

## Problem Statement

Design a simple adventure game where the player explores a mysterious cave. The player must make choices that lead to different outcomes. Each location or event in the game should be handled by a separate function to demonstrate modular programming.

## Game Flow

```text
Start Adventure
       │
       ▼
Choose Path
   ┌───────────────┐
   │               │
Forest          Cave
   │               │
Treasure      Dragon
   │               │
Victory        Fight or Run
```

## Algorithm

1. Display a welcome message.
2. Ask the player to choose a path.
3. If the player chooses the forest, guide them to the treasure.
4. If the player chooses the cave, let them encounter a dragon.
5. If the player fights, determine the outcome.
6. If the player runs, end the game safely.
7. Display the final result.

## Python Program

```python
def welcome():
    print("================================")
    print(" Welcome to the Adventure Game ")
    print("================================")


def forest():
    print("\nYou walk through a peaceful forest.")
    print("You discover a hidden treasure chest!")
    print("🎉 Congratulations! You Win!")


def dragon():
    print("\nA giant dragon appears!")
    choice = input("Do you want to fight or run? ").lower()

    if choice == "fight":
        print("You bravely fight the dragon.")
        print("🏆 You defeat the dragon and become a hero!")
    elif choice == "run":
        print("You escape safely.")
        print("Game Over.")
    else:
        print("The dragon is confused by your answer!")
        print("Game Over.")


def start_game():
    welcome()

    print("\nChoose your path:")
    print("1. Forest")
    print("2. Cave")

    option = input("Enter your choice (1 or 2): ")

    if option == "1":
        forest()
    elif option == "2":
        dragon()
    else:
        print("Invalid choice. Game Over.")


start_game()
```

## Sample Output

```text

Enter your choice (1 or 2): 2

A giant dragon appears!
Do you want to fight or run? fight
```

# Best Practices for Writing Functions

* Give functions meaningful names such as `calculateTotal()` or `displayMenu()`.
* Keep each function focused on a single responsibility.
* Pass data using parameters instead of relying on global variables whenever possible.
* Return results instead of printing them when the value may be reused.
* Reuse functions to avoid duplicate code and make maintenance easier.

# Key Takeaways

* A **function** is a reusable block of code that performs a specific task.
* Functions are defined using the `def` keyword and executed by calling them.
* **Parameters** allow functions to work with different input values.
* **Return values** enable functions to send results back to the caller.
* **Local variables** exist only within a function, while **global variables** can be accessed throughout the program.
* Breaking large problems into small functions produces cleaner, more maintainable, and reusable code.
