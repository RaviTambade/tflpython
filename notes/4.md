# What is a Module?

A **module** is a Python file (`.py`) that contains reusable code such as functions, classes, and variables. Think of a module as a **toolbox**.

```text
+-------------------------+
|      math.py            |
|-------------------------|
| sqrt()                  |
| pow()                   |
| factorial()             |
| sin()                   |
| cos()                   |
+-------------------------+
```

Instead of writing these functions yourself, you simply import the module.


# What is a Package?

A **package** is a collection of related modules organized into directories. Imagine a shopping mall.

```text
Shopping Mall
│
├── Electronics
│      TV
│      Mobile
│      Laptop
│
├── Clothing
│      Shirts
│      Jeans
│
└── Food Court
       Pizza
       Coffee
```

Similarly,

```text
Package
│
├── module1.py
├── module2.py
├── module3.py
```

A package helps organize large projects into manageable parts.

# Project – Build a Simple Web Scraper

## Problem Statement

Create a Python application that retrieves the HTML content of a web page and extracts product names from a sample **TFLStore** catalog page. This demonstrates how modules and external packages work together.

> **Note:** This project should be used only on websites that you own or have permission to scrape. Always review a website's terms of service and `robots.txt` before scraping.

## Architecture

```text
                User
                  │
                  ▼
        requests.get(url)
                  │
                  ▼
        HTML Page Downloaded
                  │
                  ▼
      BeautifulSoup Parser
                  │
                  ▼
      Find Product Elements
                  │
                  ▼
     Display Product Names
```

## Install Required Packages

```bash
pip install requests
pip install beautifulsoup4
```

## Sample HTML (TFLStore Product Page)

```html
<div class="product">
    <h2>Python Programming Book</h2>
    <span class="price">₹799</span>
</div>

<div class="product">
    <h2>Mechanical Keyboard</h2>
    <span class="price">₹2499</span>
</div>

<div class="product">
    <h2>Wireless Mouse</h2>
    <span class="price">₹999</span>
</div>
```


## Python Program

```python
import requests
from bs4 import BeautifulSoup

url = "https://example.com/tflstore/products"

response = requests.get(url)

if response.status_code == 200:
    soup = BeautifulSoup(response.text, "html.parser")

    products = soup.find_all("div", class_="product")

    print("Products Available\n")

    for product in products:
        name = product.find("h2").text.strip()
        price = product.find("span", class_="price").text.strip()

        print(name)
        print(price)
        print("---------------------")
else:
    print("Unable to retrieve the webpage.")
```

* Use meaningful module and package names.
* Group related functionality into the same package.

# Key Takeaways

* A **module** is a single Python file containing reusable code.
* A **package** is a collection of related modules organized into directories.
* The `import` statement enables code reuse from built-in, custom, and third-party modules.
* **pip** is the standard tool for installing external Python packages.
* Libraries such as `requests` and `BeautifulSoup` make it easy to build applications like web scrapers by handling networking and HTML parsing.
