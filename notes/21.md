
## 🌱 Python Control Structures — Making Programs Think and Repeat

> **“A smart program knows when to decide and when to repeat.”**

### 🌻 Mentor Kickstart

Yesterday, our Python programs learned how to **store information** using variables and data types. But imagine a program that can only execute statements one after another. An ATM would always dispense money. A traffic signal would always stay green. A login system would welcome everyone—even with the wrong password! A useful program needs to **make decisions** and **repeat tasks**.  That is where **control structures** come into the picture.

 

# 1. What are Control Structures?

Control structures determine **how a program flows**. They help a program:

* Make decisions
* Repeat tasks
* Choose different execution paths
* Solve problems intelligently

Think of control structures as the **traffic police of your program**. They decide:  **Which path should the program take?** and  **How many times should something happen?** 

 

# 2. Decision Making Using `if`

Let's take a real-world example. Suppose a website allows only adults to register.

```text
Age >= 18?
     |
   Yes ──→ Allow Registration
     |
    No ──→ Reject Registration
```

Python:

```python
age = int(input("Enter your age: "))

if age >= 18:
    print("You are eligible to register.")
```

The `if` statement executes its block **only when the condition is true**.

### Syntax

```python
if condition:
    statement
```

---

# 3. `if...else`

Sometimes there are only **two possible outcomes**.

For example:

```text
Marks >= 40?
      |
   Yes ──→ PASS
      |
    No ──→ FAIL
```

Python:

```python
marks = int(input("Enter Marks: "))

if marks >= 40:
    print("Congratulations! You Passed.")
else:
    print("Better Luck Next Time.")
```

### Mentor's Thought

Whenever the question is:  **"If this happens, do A; otherwise do B."** Think about:

```python
if...else
```
 

# 4. `if...elif...else`

Real-world problems often have **more than two choices**. Consider student grades:

| Marks    | Result      |
| -------- | ----------- |
| 75+      | Distinction |
| 60–74    | First Class |
| 40–59    | Pass        |
| Below 40 | Fail        |

Python:

```python
marks = int(input("Enter Marks: "))

if marks >= 75:
    print("Distinction")
elif marks >= 60:
    print("First Class")
elif marks >= 40:
    print("Pass")
else:
    print("Fail")
```

Here Python checks the conditions **from top to bottom**. Once a matching condition is found, its block executes.

# 6. Python `match...case` — Modern Switch-Style Decision Making

Python does not traditionally have a `switch` statement like C#, Java, or C++. Modern Python provides:

```python
match...case
```

Example:

```python
choice = 2

match choice:
    case 1:
        print("Add Customer")

    case 2:
        print("Update Customer")

    case 3:
        print("Delete Customer")

    case 4:
        print("Exit")

    case _:
        print("Invalid choice")
```

Here:

```python
case _:
```

works like a **default case**.

### Mentor's Note

Don't memorize:  "`match` is Python's switch." Understand the bigger idea:  **`match...case` is useful when a program needs to match a value or pattern against multiple possibilities.**

 

# 7. Loops — Repeating Work

Imagine writing:

```text
Welcome Ravi
Welcome Ravi
Welcome Ravi
Welcome Ravi
Welcome Ravi
```

Writing the same statement five times is unnecessary.

Instead:

```python
for i in range(5):
    print("Welcome to Transflower")
```

A loop allows us to **repeat work automatically**. 

 

# 8. `for` Loop

A `for` loop is commonly used when we want to iterate over a sequence or a known range of values.

```python
for i in range(5):
    print("Welcome to Transflower")
```

Output:

```text
Welcome to Transflower
Welcome to Transflower
Welcome to Transflower
Welcome to Transflower
Welcome to Transflower
```

 

# 9. Understanding `range()`

Consider:

```python
range(5)
```

It represents:

```text
0  1  2  3  4
```

Notice something important:  **The ending value is excluded.** Another example:

```python
for i in range(1, 6):
    print(i)
```

Output:

```text
1
2
3
4
5
```

Think:

```text
range(start, stop)
             ↑
       stop is excluded
```

For input `5`:

# 11. `while` Loop

A `while` loop continues **as long as a condition remains true**. Think about a lift:  Keep moving while there are floors remaining.

Example:

```python
count = 1

while count <= 5:
    print(count)
    count += 1
```

Output:

```text
1
2
3
4
5
```

The important part is:

```python
count += 1
```

Without changing the condition-related value, we could accidentally create an **infinite loop**.

 

# 12. `for` vs `while`

| `for` Loop                                | `while` Loop                                 |
| ----------------------------------------- | -------------------------------------------- |
| Commonly used for sequences/ranges        | Commonly used for condition-based repetition |
| Iteration progresses through the iterable | Developer controls the condition             |
| Good for known collections/ranges         | Good when repetition depends on a condition  |
| Example: process 10 records               | Example: keep asking until valid input       |

### Mentor's Rule

Don't ask: "Which loop is better?" Ask:  **"Do I have a sequence to iterate over, or a condition that controls repetition?"**


# 13. Nested Control Structures

Real applications often combine decisions and loops. 

Example:

```python
for i in range(1, 6):

    if i % 2 == 0:
        print(i, "is Even")
    else:
        print(i, "is Odd")
```

Output:

```text
1 is Odd
2 is Even
3 is Odd
4 is Even
5 is Odd
```

Here we have:

```text
for loop
   ↓
   if condition
       ↓
   decision
```

This is called a **nested control structure**.

# 16. Mini Project — Number Guessing Game 🎯

Now let's combine:

```text
Variables
   +
Input
   +
if / elif / else
   +
while loop
   +
random module
```

### Problem Statement

The computer randomly selects a number between **1 and 100**. The user keeps guessing until the correct number is found. After every incorrect guess:

```text
Too Low
```

or

```text
Too High
```

is displayed. Finally, the program reports the number of attempts. 

### Python Program

```python
import random

secret_number = random.randint(1, 100)
attempts = 0

print("=== Number Guessing Game ===")
print("I have selected a number between 1 and 100.")

while True:

    guess = int(input("Enter your guess: "))
    attempts += 1

    if guess < secret_number:
        print("Too Low! Try Again.")

    elif guess > secret_number:
        print("Too High! Try Again.")

    else:
        print("🎉 Congratulations!")
        print("You guessed the correct number.")
        print("Attempts:", attempts)
        break
```

### What did we learn from this project?

```text
random
   ↓
Generate data

while
   ↓
Repeat interaction

if / elif / else
   ↓
Make decisions

break
   ↓
Terminate the loop
```

This is where programming fundamentals begin to become **application logic**.
