# FastAPI AuthAPI


Let's extend the previous OTP API architecture into an `AuthAPI` that stores user records in a `users.json` file.

We will implement three core operations:

- Register — create a new user account.
- Login — validate email and password.
- Reset Password — verify the user's identity using an OTP, then update the password.

We'll retain the same layered architecture: Router → Controller → Service → Repository. The repository will handle JSON file storage, while the service will handle authentication rules.

## 1. Architecture

Client / Postman / Swagger

Register · Login · Reset Password

Router — `router.py`

Maps HTTP requests to endpoints

Controller — `controller.py`

Handles requests and responses

Service — `service.py`

Authentication, password hashing, OTP verification

Repository — `repository.py`

Reads and writes `users.json`

```
from pydantic import BaseModel, Field


class RegisterRequest(BaseModel):
    name: str = Field(min_length=2, max_length=100)
    email: str = Field(min_length=5, max_length=254)
    password: str = Field(min_length=8, max_length=128)


class LoginRequest(BaseModel):
    email: str
    password: str


class ResetOTPRequest(BaseModel):
    email: str


class ResetPasswordRequest(BaseModel):
    email: str
    otp: str = Field(pattern=r"^\d{6}$")
    new_password: str = Field(min_length=8, max_length=128)
```

These models define the JSON accepted by each endpoint. For a production application, add robust email validation and stronger password policy checks.

## 5. Repository layer — `users.json`

File: `repository.py`

The repository owns all user-file operations. Passwords are stored as hashes, never as plaintext.

```
import json
import os
import tempfile
from pathlib import Path


class UserRepository:

    def __init__(self):
        self.file_path = Path(__file__).resolve().parent / "users.json"

        if not self.file_path.exists():
            self._write_users([])

    def _read_users(self):
        with open(self.file_path, "r", encoding="utf-8") as file:
            return json.load(file)

    def _write_users(self, users):
        # Write to a temporary file before replacing the data file.
        fd, temp_path = tempfile.mkstemp(
            dir=self.file_path.parent,
            suffix=".tmp"
        )

        try:
            with os.fdopen(fd, "w", encoding="utf-8") as file:
                json.dump(users, file, indent=4)

            os.replace(temp_path, self.file_path)

        finally:
            if os.path.exists(temp_path):
                os.remove(temp_path)

    def find_by_email(self, email: str):
        users = self._read_users()

        for user in users:
            if user["email"].lower() == email.lower():
                return user

        return None

    def create_user(self, user: dict):
        users = self._read_users()

        # Prevent duplicate email registration.
        if any(
            item["email"].lower() == user["email"].lower()
            for item in users
        ):
            return False

        users.append(user)
        self._write_users(users)

        return True

    def update_password(self, email: str, password_hash: str):
        users = self._read_users()

        for user in users:
            if user["email"].lower() == email.lower():
                user["password_hash"] = password_hash
                self._write_users(users)

                return True

        return False
```

Mentor's note: The repository is the only layer that knows the location and format of `users.json`. If we later move users to MySQL, this is the layer we would replace.

## 6. Service layer — authentication logic

File: `service.py`

This layer handles registration, login, password hashing and the OTP reset workflow.

```
import hashlib
import secrets
import time


class AuthService:

    def __init__(self, repository):
        self.repository = repository
        self.reset_otps = {}

    def _hash_password(self, password: str) -> str:
        # Demo only: use Argon2 or bcrypt in production.
        return hashlib.sha256(password.encode("utf-8")).hexdigest()

    def _verify_password(self, password: str, password_hash: str) -> bool:
        return secrets.compare_digest(
            self._hash_password(password),
            password_hash
        )

    def register(self, name: str, email: str, password: str):
        user = {
            "name": name,
            "email": email.lower(),
            "password_hash": self._hash_password(password)
        }

        return self.repository.create_user(user)

    def login(self, email: str, password: str):
        user = self.repository.find_by_email(email)

        if not user:
            return False

        return self._verify_password(
            password,
            user["password_hash"]
        )

    def request_password_reset(self, email: str):
        user = self.repository.find_by_email(email)

        # Avoid revealing whether an account exists.
        if not user:
            return None

        otp = f"{secrets.randbelow(1_000_000):06d}"

        self.reset_otps[email.lower()] = {
            "otp": otp,
            "expires_at": time.time() + 300,
            "attempts": 0
        }

        # Demo only. Production should send this via an email/SMS provider.
        return otp

    def reset_password(
        self,
        email: str,
        otp: str,
        new_password: str
    ):
        key = email.lower()
        record = self.reset_otps.get(key)

        if not record:
            return False

        # Check OTP expiration.
        if time.time() >= record["expires_at"]:
            self.reset_otps.pop(key, None)
            return False

        # Limit verification attempts.
        if record["attempts"] >= 5:
            self.reset_otps.pop(key, None)
            return False

        # Verify OTP.
        if not secrets.compare_digest(record["otp"], otp):
            record["attempts"] += 1
            return False

        # Update password hash.
        updated = self.repository.update_password(
            key,
            self._hash_password(new_password)
        )

        # OTP must not be reusable.
        self.reset_otps.pop(key, None)

        return updated
```

The password hash uses PBKDF2 with a random salt and 600,000 iterations. The reset OTP expires after five minutes, and five incorrect attempts invalidate it.

Note that reset OTPs are stored in memory here, while user records are stored in the JSON file. A restart clears pending reset OTPs.

## 7. Controller layer — `controller.py`

The controller translates service outcomes into HTTP responses.

```
from fastapi import HTTPException

from schemas import (
    RegisterRequest,
    LoginRequest,
    ResetOTPRequest,
    ResetPasswordRequest
)
from service import AuthService


class AuthController:

    def __init__(self, service: AuthService):
        self.service = service

    def register(self, request: RegisterRequest):
        success = self.service.register(
            request.name,
            request.email,
            request.password
        )

        if not success:
            raise HTTPException(
                status_code=409,
                detail="An account with this email already exists"
            )

        return {
            "message": "Registration successful"
        }

    def login(self, request: LoginRequest):
        success = self.service.login(
            request.email,
            request.password
        )

        if not success:
            raise HTTPException(
                status_code=401,
                detail="Invalid email or password"
            )

        # Credential verification only.
        # JWT/session creation is a separate step.
        return {
            "message": "Login successful"
        }

    def request_password_reset(self, request: ResetOTPRequest):
        otp = self.service.request_password_reset(
            request.email
        )

        if otp is not None:
            # Demo only: never return an OTP in production.
            return {
                "message": "Reset OTP generated",
                "demo_otp": otp
            }

        return {
            "message": (
                "If the account exists, reset instructions "
                "will be sent"
            )
        }

    def reset_password(self, request: ResetPasswordRequest):
        success = self.service.reset_password(
            request.email,
            request.otp,
            request.new_password
        )

        if not success:
            raise HTTPException(
                status_code=400,
                detail="Invalid, expired, or unavailable reset OTP"
            )

        return {
            "message": "Password reset successful"
        }
```

## 13. What should students learn from this project?

| Requirement         | Implementation                     |
| ------------------- | ---------------------------------- |
| API endpoints       | FastAPI Router                     |
| Request validation  | Pydantic schemas                   |
| Business logic      | AuthService                        |
| User persistence    | JSON repository                    |
| Password protection | Salted PBKDF2 hash                 |
| Login verification  | Constant-time hash comparison      |
| Password recovery   | OTP with expiry and attempt limits |
| HTTP error handling | FastAPI `HTTPException`            |

### Important production improvements

This is a teaching project. Before exposing it to real users:

- Replace `users.json` with a database such as MySQL or PostgreSQL. Concurrent JSON file writes can lose updates, and this implementation is not designed for multiple worker processes.
- Deliver OTPs through a trusted email/SMS provider; never return the OTP to the client.
- Add rate limiting, HTTPS, email verification, and secure logging.
- Issue a signed JWT or establish a secure session after successful login. The current login endpoint checks credentials but does not create an authenticated session.
- Add durable, shared OTP storage and atomic attempt limits if multiple application instances are used.

Transflower Mentor takeaway: Authentication is not just checking a username and password. It is a sequence of responsibilities: validate input, verify identity, protect credentials, persist user data, and manage access securely. Build the fundamentals first, then introduce JWT, databases, and production deployment.
