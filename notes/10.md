
# 👨‍🏫 Lambda Function in Python

> **“Don't write a big machine when a small tool can solve the problem.”**

When students begin learning Python, they normally learn how to create functions using `def`. For example:

```python
def calculate_premium(amount, rate):
    return amount * rate
```

This is perfectly fine. But sometimes, while working on **TFLInsurance**, we need to perform a very small operation:

* Check whether a policy is active
* Calculate a discounted premium
* Extract policy coverage
* Sort policies by premium
* Filter policies above a particular coverage
* Transform a collection of policy records

Do we really need to create a separate named function every time? Sometimes the answer is **No**. That is where a **lambda function** becomes useful.

# 2. What Is a Lambda Function?

A **lambda function** in Python is a small anonymous function. In simple words:

> **Lambda is a quick way of writing a small function without explicitly using `def`.**

A lambda:

* can accept multiple arguments
* contains one expression
* automatically returns the result of that expression

For example:

```python
lambda x: x * x
```

means:

```text
Take x
   │
   ▼
Calculate x × x
   │
   ▼
Return the result
```

 
# 3. Syntax

The basic syntax is:

```python
lambda arguments: expression
```

For example:

```python
lambda x: x * 2
```

Here:

```text
lambda
  │
  ├── x          → argument
  │
  └── x * 2      → expression
```

The result of the expression is automatically returned.

 

# 4. Simple TFLInsurance Example

Suppose we want to calculate a 10% discount on a premium. Normal function:

```python
def calculate_discount(premium):
    return premium * 0.90
```

Using it:

```python
print(calculate_discount(50000))
```

Output:

```text
45000.0
```

Now write the same logic using lambda:

```python
calculate_discount = lambda premium: premium * 0.90

print(calculate_discount(50000))
```

Output:

```text
45000.0
```

Both approaches produce the same result.

The lambda version is simply a compact way of expressing the small operation.

# 8. `map()` — Transform Insurance Data

Suppose the Insurance Manager says:

> “Apply a 10% discount to every policy premium.”

We could write a loop. But we can also use `map()` with lambda.

```python
discounted = list(
    map(
        lambda p: {
            **p,
            "discounted_premium": p["premium"] * 0.90
        },
        policies
    )
)

print(discounted)
```

The lambda says:

```python
lambda p: {
    **p,
    "discounted_premium": p["premium"] * 0.90
}
```

Meaning:

> Take one policy and create a new policy dictionary containing the discounted premium.

Conceptually:

```text
Policy
   │
   ▼
lambda
   │
   ▼
Calculate premium × 0.90
   │
   ▼
New policy data
```

 

# 9. `filter()` — Find High-Coverage Policies

Now the Insurance Manager asks:

> “Show me policies having coverage greater than ₹10 lakh.”

We can write:

```python
high_coverage = list(
    filter(
        lambda p: p["coverage"] > 1000000,
        policies
    )
)

print(high_coverage)
```

The lambda:

```python
lambda p: p["coverage"] > 1000000
```

returns either:

```text
True
```

or:

```text
False
```

for every policy.

Think:

```text
Policy 1 → coverage > 10 lakh → True
Policy 2 → coverage > 10 lakh → True
Policy 3 → coverage > 10 lakh → False
Policy 4 → coverage > 10 lakh → True
```

`filter()` keeps the policies for which the condition is true.

 

# 10. `sorted()` — Sort Policies by Premium

Suppose the manager asks:

> “Show policies from highest premium to lowest premium.”

We can write:

```python
sorted_policies = sorted(
    policies,
    key=lambda p: p["premium"],
    reverse=True
)

print(sorted_policies)
```

Here:

```python
lambda p: p["premium"]
```

tells Python:

> “Use the premium value as the sorting key.”

Conceptually:

```text
Policy
   │
   ▼
lambda p: p["premium"]
   │
   ▼
Premium
   │
   ▼
Sorting
```

# 13. `def` vs `lambda`

A useful mentor comparison:

| `def`                                 | `lambda`                         |
| ------------------------------------- | -------------------------------- |
| Named function                        | Anonymous function               |
| Suitable for larger logic             | Suitable for small logic         |
| Can contain multiple statements       | One expression                   |
| Good for reuse                        | Good for short operations        |
| Easier to document/test independently | Convenient inline                |
| Better for substantial business rules | Better for small transformations |

For example:

### Use `def`

```python
def calculate_policy_premium(
    coverage,
    age,
    policy_term,
    risk_factor
):
    # Larger business calculation
    ...
```

### Use `lambda`

```python
lambda p: p["premium"] * 0.90
```


# 14. Mentor's Wisdom

> **`def` = a properly designed machine**
>
> **`lambda` = a small pocket calculator**

If the logic is:

```text
small
simple
temporary
obvious
```

lambda may be appropriate.

If the logic is:

```text
large
complex
reused
business-critical
```

prefer a named function. For example, don't hide a complicated insurance calculation inside a huge lambda.

Bad design:

```python
lambda p: complicated_business_rule(p)
```

when the business rule itself deserves a meaningful function.

Better:

```python
def calculate_maturity_amount(policy):
    ...
```

```python

    by="Premium",
```

If we specifically want to demonstrate a lambda as a sorting key:


Here the lambda simply returns the column unchanged. In many Pandas cases, a lambda isn't necessary for straightforward sorting, but `key=` becomes useful when the sorting transformation itself is customized.

# 35. Interview Questions

### Q1. What is a lambda function?

**Answer:**

A lambda is a small anonymous function expression that can accept arguments and contains a single expression whose result is returned automatically.

 

### Q2. What is the syntax?

```python
lambda arguments: expression
```
 

### Q3. Can lambda accept multiple arguments?

Yes.

```python
calculate = lambda x, y: x + y

print(calculate(10, 20))
```

Output:

```text
30
```

 

### Q4. Can a lambda contain multiple statements?

No. A lambda contains a single expression.

For more complex logic, use `def`.

 

### Q5. Where are lambda functions commonly used?

Common examples include:

```text
map()
filter()
sorted()
```

and various data-processing APIs.

 

### Q6. What is the difference between `def` and `lambda`?

`def` is generally preferable for substantial, named, reusable functions. `lambda` is convenient for short function expressions used locally.
 

### Q7. Is lambda always better than `def`?

No.

> **Use the simplest construct that makes the code clear.**
