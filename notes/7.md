## 1️⃣ From Variable → File

Suppose we have:

```python
policy_number = "POL1001"
customer_name = "Sneha"
premium = 25000
```

This data lives in memory.

```text
Python Program
      ↓
    RAM
      ↓
policy_number
customer_name
premium
```

When the program terminates:

```text
Program stopped
      ↓
Memory released
      ↓
Data gone
```

So we need **file storage**.

```text
Python Program
      ↓
   File System
      ↓
 policies.json
```

# 3️⃣ Reading a File

Python provides the `open()` function.

```python
file = open("policies.json", "r")
```

Here:

```text
"r" → read
"w" → write
"a" → append
```

But friends, there is a better practice.

Use:

```python
with open("policies.json", "r") as file:
    data = file.read()
```

Why `with`?

Because Python automatically manages the file resource.

 

# 4️⃣ Read JSON Data

A JSON file contains text. We need to convert JSON text into Python objects. Python provides the `json` module.

```python
import json
```

Then:

```python
with open("policies.json", "r") as file:
    policies = json.load(file)
```

Now:

```python
print(policies)
```

gives us Python data such as:

```python
[
    {
        "policy_number": "POL1001",
        "customer_name": "Sneha",
        "premium": 25000,
        "status": "Active"
    }
]
```


# 5️⃣ JSON → Python

This is an important concept.

```text
              json.load()
JSON File  ───────────────→ Python Object
```

For example:

```json
{
    "policy_number": "POL1001",
    "premium": 25000
}
```

becomes approximately:

```python
{
    "policy_number": "POL1001",
    "premium": 25000
}
```

A JSON object becomes a Python `dict`. A JSON array becomes a Python `list`.

 

# 6️⃣ Python → JSON

Now suppose we create a new policy:

```python

    "policy_number": "POL1003",
```

The conversion is:

```text
Python Object

```

 

# 7️⃣ Add a New Policy

But be careful. If we use:

```python
open("policies.json", "w")
```

we overwrite the existing file. For TFLInsurance, we first read the existing policies.

```python
import json

with open("policies.json", "r") as file:
    policies = json.load(file)

new_policy = {
    "policy_number": "POL1003",
    "customer_name": "Amit",
    "premium": 18000,
    "status": "Active"
}

policies.append(new_policy)

with open("policies.json", "w") as file:
    json.dump(policies, file, indent=4)
```

Now the file contains three policies.

 
# 8️⃣ Find a Policy

Now let's build a small TFLInsurance function.

```python
def find_policy(policy_number):

    with open("policies.json", "r") as file:
        policies = json.load(file)

    for policy in policies:

        if policy["policy_number"] == policy_number:
            return policy

    return None
```

Call it:

```python
policy = find_policy("POL1001")

print(policy)
```

Output:

```text
{
    'policy_number': 'POL1001',
    'customer_name': 'Sneha',
    'premium': 25000,
    'status': 'Active'
}
```

# 9️⃣ What If the File Doesn't Exist?

This is where our previous topic—**Exception Handling**—becomes useful.

Suppose:

```python
with open("policies.json", "r") as file:
```

but the file doesn't exist. Python raises:

```text
FileNotFoundError
```

We can handle it:

```python
import json

try:

    with open("policies.json", "r") as file:
        policies = json.load(file)

except FileNotFoundError:

    print("Policy file does not exist.")
    policies = []
```

Now our application doesn't crash.

 

# 🔟 What If JSON Is Corrupted?

Suppose somebody accidentally changes:

```json
[
    {
        "policy_number": "POL1001",
        "premium": 25000
    }
```

The JSON is incomplete. Python may raise:

```text
JSONDecodeError
```

We can handle it:

```python
import json

try:

    with open("policies.json", "r") as file:
        policies = json.load(file)

except FileNotFoundError:

    print("Policy file not found.")
    policies = []

except json.JSONDecodeError:

    print("Policy file contains invalid JSON.")
    policies = []
```

Now we have connected:

```text
File Handling
      +
JSON
      +
Exception Handling
```

# 1️⃣1️⃣ TFLInsurance Policy Repository

Now let's move toward software engineering. Instead of writing file code everywhere:

```python
open(...)
json.load(...)
json.dump(...)
```

we create a repository.

```python
class PolicyRepository:

    def __init__(self, filename):
        self.filename = filename

    def get_all(self):

        try:

            with open(self.filename, "r") as file:
                return json.load(file)

        except FileNotFoundError:
            return []

        except json.JSONDecodeError:
            return []
```

Then:

```python
repository = PolicyRepository("policies.json")
policies = repository.get_all()
print(policies)
```

Now the application has a cleaner architecture.
