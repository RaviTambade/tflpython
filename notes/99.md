# Python – Simple Database Connectivity Using MySQL

Let's understand how to connect a Python application with a MySQL database and perform basic CRUD operations.

Learning objective: Understand how Python communicates with a relational database.

## 2. Install Python MySQL connector

Open the terminal:

```
pip install mysql-connector-python
```

Verify installation:

```
pip show mysql-connector-python
```

## 3. Create MySQL database and table

Execute these SQL commands in MySQL Workbench.

```
CREATE DATABASE company_db;

USE company_db;

CREATE TABLE employees
(
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100),
    email VARCHAR(100),
    salary DECIMAL(10,2)
);
```

Insert sample records:

```
INSERT INTO employees(name, email, salary)
VALUES
('Amit', 'amit@gmail.com', 35000),
('Sneha', 'sneha@gmail.com', 40000),
('Rahul', 'rahul@gmail.com', 45000);
```

## 4. Python database connectivity

Create a file named `main.py`.

```
import mysql.connector

def get_connection():

    connection = mysql.connector.connect(
        host="localhost",
        user="root",
        password="your_password",
        database="banking_db",
        autocommit=False
    )

    return connection

```

Run:

```
python main.py
```

Expected output:

```
Database connected successfully!

(1, 'Amit', 'amit@gmail.com', 35000.00)
(2, 'Sneha', 'sneha@gmail.com', 40000.00)
(3, 'Rahul', 'rahul@gmail.com', 45000.00)
```

## 5. Perform CRUD operations using Python

CRUD means Create, Read, Update and Delete.

A. Create – Insert employee

```
sql = """
INSERT INTO employees(name, email, salary)
VALUES (%s, %s, %s)
"""

values = ("Priya", "priya@gmail.com", 50000)

cursor.execute(sql, values)
connection.commit()

print("Employee inserted successfully")

```

B. Read – Fetch employees

```
 cursor.execute("SELECT * FROM employees")

for row in cursor.fetchall():
    print(row)
```

C. Update – Modify employee salary

```
 sql = """
UPDATE employees
SET salary = %s
WHERE id = %s
"""

cursor.execute(sql, (55000, 1))
connection.commit()

print("Employee updated successfully")
```

D. Delete – Remove employee

```
 sql = "DELETE FROM employees WHERE id = %s"

cursor.execute(sql, (3,))
connection.commit()

print("Employee deleted successfully")
```

## 6. Understand the important Python database functions

| Function     | Purpose                       |
| ------------ | ----------------------------- |
| `connect()`  | Establish database connection |
| `cursor()`   | Create SQL execution object   |
| `execute()`  | Execute SQL statement         |
| `fetchone()` | Fetch one record              |
| `fetchall()` | Fetch all records             |
| `commit()`   | Save database changes         |
| `rollback()` | Undo uncommitted changes      |
| `close()`    | Close connection/cursor       |
