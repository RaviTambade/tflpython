# TFL Insurance API

A simple Policy Management REST API built using FastAPI.

## CRUD Operations

- Create Policy
- Get All Policies
- Get Policy By ID
- Update Policy
- Delete Policy

## Technologies

- Python
- FastAPI
- Pydantic
- Uvicorn
- Pytest

## Run Project

uvicorn app.main:app --reload
